# Munowatch Pro — release feed

This repository hosts the Android app's update files and APK downloads
(published through jsDelivr).

| File | Purpose |
|---|---|
| `apks/MunowatchPro_latest.apk` | always the newest build |
| `apks/MunowatchPro_v<version>.apk` | pinned releases (never removed) |
| `update.json` · `dialog/update.json` | version metadata read by the app's updater |

CDN links used by the app:

```
https://cdn.jsdelivr.net/gh/tfastdigital/munowatch-update-panel@main/apks/MunowatchPro_latest.apk
https://raw.githubusercontent.com/tfastdigital/munowatch-update-panel/main/apks/MunowatchPro_latest.apk
```
